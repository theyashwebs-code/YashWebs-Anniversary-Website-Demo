# YashWebs — Anniversary Website Demo 🎉

A cinematic and interactive anniversary website demo created by **YashWebs**.

This project demonstrates how a business anniversary can be transformed into a memorable digital experience with interactive storytelling, animations, memories, stars, and celebration-focused sections.

## 🌐 Live Demo

🔗 https://theyashwebs-code.github.io/YashWebs-Anniversary-Website-Demo/

## ✨ Features

- 🔐 Interactive demo access screen
- 🚀 Cinematic rocket launch animation
- 🌌 Animated space-themed experience
- ✨ Interactive Star Navigator
- ⭐ Collectible stars mini-game
- 🧩 Interactive verification quiz
- 🎬 Cinematic introduction
- 📖 Anniversary memory section
- 📸 Memory gallery
- 💌 Anniversary message
- 🚀 Interactive celebration moment
- 🌠 Interactive constellation experience
- 🖼️ Clickable memory stars
- 🔄 Restart Demo functionality
- 📱 Fully responsive design
- 💻 Desktop, tablet, and mobile support

## 🎨 Design

The website uses a cinematic space-inspired visual style featuring:

- Animated starfields
- Glassmorphism UI
- Neon accents
- Smooth transitions
- Interactive animations
- Large cinematic typography
- Responsive layouts
- Interactive storytelling

The goal is to make the anniversary experience feel like a **digital journey rather than a traditional static website**.
